# 🍣 Danny's Diner SQL Case Study

## Overview

This repository contains my solutions for **Case Study #1 - Danny's Diner** from the **8 Week SQL Challenge**.

## Database Tables

* **sales**
* **menu**
* **members**

## Questions Solved

1. Total amount spent by each customer
2. Number of visits by each customer
3. First item purchased by each customer
4. Most purchased item
5. Most popular item for each customer
6. First item purchased after becoming a member
7. Item purchased before becoming a member
8. Total items and amount spent before membership
9. Customer reward points
10. January bonus points

## SQL Concepts Used

* SELECT
* WHERE
* GROUP BY
* ORDER BY
* JOIN
* CASE
* Aggregate Functions
* Window Functions
* CTE

## Tools Used

* MySQL
* MySQL Workbench


## Files

* `schema.sql` – Database tables and sample data
* `solutions.sql` – SQL solutions
* `README.md` – Project description

## Learning Outcome

This project helped me practice SQL queries, joins, aggregations, window functions, and solving real-world business problems.
